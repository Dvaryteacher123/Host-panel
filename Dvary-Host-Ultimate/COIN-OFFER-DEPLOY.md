# Coin Offer Deploy

Admin flow:
1. Admin -> Offers.
2. In **GIVE COINS TO CUSTOMER**, enter customer email and amount to give balance Coins.
3. In **CREATE COIN OFFER FOR DEPLOY**, choose `Specific Bot`, select the bot, and set `Offer price (coins)` (for example 100).
4. Customer opens Deploy Bot or Checkout. The Coin section is visible on every bot; only the assigned bot has an enabled offer.
5. Customer enters server name and Coins and deploys.

Coins are not sold by this offer system. They are granted by admin. The offer is scoped to the specific customer and specific bot.
